# Práctica de Patrones de Diseño y Estructuras de Datos en Java

Ejercicios de repaso para el examen final de Programación en Java, organizados por tema.
Pensados para resolverse **completando el código** (sin solución incluida), al mismo estilo
y nivel de dificultad que se trabajó en la sesión de preparación.

Cada tema tiene dos versiones:
- **`.html`** → para abrir en el navegador, con los bloques de código resaltados en **fondo azul**.
- **`.md`** → la misma versión en texto plano/Markdown (se ve bien directamente en GitHub).

## Cómo usar este repo

1. Elegí un archivo (`.html` para la versión con fondo azul en el código, o `.md` para texto plano).
2. Copiá el código Java de un ejercicio a tu IDE o a un compilador online.
3. Completá las partes marcadas con `// Completar`.
4. Compilá y probá con tus propios `main` de prueba.

No se incluyen soluciones a propósito, para practicar razonando como en el examen.
